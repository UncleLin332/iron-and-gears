# Iron & Gears Combo 系統設計文件

更新日期：2026-06-12

---

## 設計理念

當特定卡牌組合同時在場時，觸發：
1. **故事彈窗**（3.2 秒，可點擊提前關閉）：顯示故事背景 + 角色台詞 + 效果說明
2. **實際遊戲效果**：對應的 Combo Skill

每個 Combo 每局只激活一次（`G.activatedCombos` Set 追蹤），避免重複彈出。

## Combo 1：【總決賽·命運宿敵】

**觸發條件：** 己方場上有 `紐約隊長·大頭森`，而對方場上有 `少林奇才·文班亞馬`（反之亦然）

**故事：** 黃銅與鐵流的頂級賽場上，地底少林的巨靈文班亞馬鎮守禁區，永不言敗的大頭森拍擊齒輪球體準備突破——誰才是真正的 MVP？

**效果（已實作）：**
- 大頭森攻擊文班亞馬時，攻擊力永久 +2（`combat()` 函式觸發）

**觸發顏色：** 橘紅 `#e07030`

## Combo 2：【發條孿生星的黃昏交響曲】

**觸發條件：** `發條先知·卡斯托爾` + `發條先知·波魯克斯` 同時在**己方**場上

**故事：** 遠古雙生 AI，卡斯托爾掌握毀滅與火炮，波魯克斯守護防禦與傳承。時隔萬年，齒輪再度咬合。

**效果（已實作）：**
- 卡斯托爾的部署效果（`dmg2rand` 對隨機敵方造成2傷）**重複觸發一次**（`doBattlecry()` 判斷）
- 任一雙星死亡時，若另一雙星在場，下回合以 1/1「發條幼星」復活（`killCard()` + `startPlayerTurn()` / `doAiTurn()` 判斷）

**觸發顏色：** 紫色 `#a060e0`

## Combo 3：【林大師與他的忠犬晶片】

**觸發條件：** `龍紋機關師·林大師` + `林大師的機械寵物` 同時在**己方**場上

**故事：** 黑煙港爆炸中，愛犬以血肉護主，林大師用龍紋機關術將記憶晶片重塑為機械寵物。晶片嗅到了久違的氣息……

**效果（已實作）：**
- 機械寵物在林大師在場期間**永久獲得攔截**（`checkCombos()` 每次部署後更新）
- 機械寵物「報廢」召喚陷阱時，若林大師在場：陷阱強化為 **3/2**，林大師**回復 2 點生命**（`killCard()` 判斷）

**觸發顏色：** 綠色 `#50c878`

## Combo 4：【天穹學院的空中補給陣線】

**觸發條件：** 己方場上有 **2 張以上**天穹族（`tribe: "天穹"`）卡牌

**故事：** 浮空島技術核心啟動，艾莉透過補給站輸送不間斷情報，知識之牆拔地而起。

**效果（已實作）：**
- Combo 激活後，每次天穹手下觸發 `eot_draw1`（回合結束抽牌），**所有天穹族手下生命值上限 +1**（`handleEndOfTurnEffects()` 判斷）

**天穹族成員：** 天穹補給站、天穹工程師·艾莉、天穹建築師·戈登、天穹聯邦學院、天穹導航員·奧莉薇亞、聯邦首席機關師·諾拉

**觸發顏色：** 藍色 `#4090d0`

## 技術架構

### 觸發流程
```
deployCard() / aiPlay()
  → checkTribeSynergy()   ← 族群共鳴（每次新卡入場）
  → checkCombos()         ← Combo 偵測（每次部署後雙方都檢查）
  → showComboDialog(id)   ← 故事彈窗（每 Combo 每局僅一次）
```

### 關鍵函式
| 函式 | 作用 |
|---|---|
| `checkCombos(who)` | 偵測四個 Combo，激活後呼叫 showComboDialog |
| `showComboDialog(id, onDone)` | 顯示故事彈窗，3.2 秒或點擊後關閉 |
| `G.activatedCombos` | Set，記錄已激活的 Combo ID，防止重複觸發彈窗 |

## 新增 Combo 的步驟

1. 在 `COMBO_DATA` 新增一筆：`{name, color, flavor, quote, effect}`
2. 在 `checkCombos()` 新增偵測條件
3. 在對應的效果函式（`combat` / `doBattlecry` / `killCard` / `handleEndOfTurnEffects`）加入效果邏輯
4. 更新本文件
